# FocusFlow - Pomodoro Timer

A modern, responsive Pomodoro Timer web application built with HTML5, CSS3, and JavaScript.

## Features
- **25-minute countdown** display with animated SVG circular progress ring.
- **Controls**: Start, Pause, Reset, and Skip.
- **Synthesized Audio Notifications**: 4 sound presets (Zen Chime, Digital Arpeggio, Warm Marimba, Classic Beeps) generated directly via the browser's native **Web Audio API** (100% offline, no external audio files required).
- **Productivity Modes**: Pomodoro (25m), Short Break (5m), Long Break (15m).
- **Session Tracking**: 4-session cycle dots with session counter.
- **Live Tab Title**: Dynamic time countdown in browser tab title.
- **Keyboard Shortcuts**: `Space` (Start/Pause), `R` (Reset), `M` (Mute).

## How to Run Locally

### Option 1: Standalone Single File (Easiest)
Simply double-click `pomodoro-standalone.html` in any web browser (Chrome, Edge, Firefox, Safari). Everything (HTML, CSS, JavaScript, and Audio synthesizer) is self-contained in this single file.

### Option 2: Folder Version
Open `index.html` directly in your browser or serve it using any local static web server.
